## Проект Avalon
Многофункциональный проект в котором я преследую сразу несколько целей.

### Цель №1. BI отчетность.
Контекст:
Текущая компания явно нуждается в качественной BI отчетности. Вся отчетность на данный момент строится через табличное представление в 1С ERP и 1С Документооборот и неинформативна для пользователей. У пользователей присутствует несформулированный запрос на аналитику в различных разрезах:
- ретроспективная аналитика;
- поиск причинно-следственных связей;
- проверка гипотез;

Глобальная цель: 
Продемонстрировать руководству компании MVP версию BI дашбордов по рабочим процессам компании на синтетических примерах с возможностью  дальнейшего переноса построения отчетности из 1С в Apache Superset, что позволит производить различную аналитику.

Метод реализации:
Локальный стенд на котором раскатаны Docker, PostgreSQL, Apache Superset.
Описан конкретный бизнес-процесс по которому собираемся делать BI отчетность.
Выделены метрики по данному бизнес-процессу.
Есть метаописание данных и привязка к бизнес-контексту.
Отчет построен по настоящей структуре данных(schema), но сами данные синтетические. 

DoD на текущем уровне культуры компании:
Руководство компании просит перенести отчет в PROD компании.

#### Цель №1.1. Создание MVP версии отчета
Контекст:
Есть новый бизнес-процесс в 1С Документообороте по работе с договорами в компании. Он описан, метрики зафиксированы.
Цель:
Создать BI-дашборд в Apache Superset в котором будут отслеживаться зафиксированные метрики по договорам.
DoD:
Рабочий отчет с рабочей бизнес-логикой и зафиксированными метриками, отчет строится на синтетических данных (Export CSV - container PostgreSQL - Apache Superset). 

#### Цель №1.2. Демонстрация MVP версии отчета руководству
Презентация созданного MVP BI-дашборд в Apache Superset. Согласие на перенос дашборда в PROD компании.

#### Цель №1.3. Создание MVP ИИ агента позволяющего создавать BI отчетность.
Контекст:
Необходимо будет сделать структурированное описание данных из 1С ДО и зафиксировать его в понятном для ИИ агенту виде.
Зафиксировать общие для бизнес-процессов компании метрики и методы их расчета.

Цель: 
Проверить возможность в долгосрочной перспективе использовать ИИ агента который в полуручном режиме можно будет использовать для создания BI отчетности в Apache Superset на основании описанных структурированных данных. 
Например:
- на основании описанных данных и зафиксированных метрик говорим агенту какую метрику мы хотим создать;
- агент пишет код для Apache Superset;
- дальше человек проверяет метрику, деплоит в прод;

DoD цели: MVP агент который может создать простой отчет на основании:
- описанного бизнес-процесса и бизнес-логики;
- полностью размеченных данных участвующих в этом бизнес-процессе;
- имеющихся инструкций как работать с этими данными, рассчитывать метрики;
