## Проект Авалон
Многофункциональный проект в котором я преследую сразу несколько целей.

### Цель №1. BI отчетность.
Контекст:
Моя компания явно нуждается в качественной BI отчетности. Вся отчетность на данный момент строится в 1С ERP и 1С Документооборот и неинформативная для ретроспективного анализа.
1С ERP - используется для учета.
1С Документооборот - используется для согласования документов в компании.
В проекте будем использовать данные из обеих 1С.

Глобальная цель: 
Продать руководству компании идею о необходимости внедрения BI аналитики через демонстрацию полезности этого функционала.

Ограничение:
AI-инструменты работают с согласованным описанием структуры данных, бизнес-логикой и синтетическими примерами. Корпоративные данные и результаты запросов им не передаются.

DoD на текущем уровне культуры компании:
На основании реализованной цели 1.1 руководство просит создать еще BI отчетность по имеющимся процессам в компании.

#### Цель №1.1. Создание MVP версии отчета
Контекст:
Есть новый бизнес-процесс в 1С Документообороте по работе с договорами в компании. Он описан, метрики зафиксированы.
Цель:
Создать BI-дашборд в Apache Superset в котором будут ослеживаться зафиксированные метрики по договорам.
DoD:
Рабочий отчет с рабочей бизнес-логикой и зафиксированными метриками, данные в отчет выгружаются 1 раз в неделю (Export CSV - container PostgreSQL - Apache Superset). Бизнес регулярно пользуется отчетом. 

#### Цель №1.2. Демонстрация MVP версии отчета руководству
Созданный MVP BI-дашборд в Apache Superset необходимо будет продемонстрировать руководству с целью дальнейшего внедрения ретроспективной аналитики.


#### Цель №1.3. Создание MVP ИИ агента позволяющего создавать BI отчетность.
Контекст:
Необходимо будет сделать структурированное описание данных из 1С ДО и зафиксировать его в понятном для ИИ агенту виде.
Зафиксировать общие для бизнес-процессов компании метрики и методы их расчета.

Цель: 
Проверить вомзожность в долгосрочной перспективе использовать ИИ агента который в полуручном режиме можно будет использовать для создания BI отчетности в Apache Superset на основании структурированных данных. 
Например:
- на основании описанных данных и зафиксированных метрик говорим агенту какую метрику мы хотим создать;
- агент пишет код для Apache SuperSet;
- дальше человек проверяет метрику, деплоит в прод;

DoD цели: MVP агент который может создать простой отчет на основании:
- описанного бизнес-процесса и бизнес-логики;
- полностью размеченных данных участвующих в этом бизнес-процессе;
- имеющихся инструкций как работать с этими данными, рассчитывать метрики;
