# О чем данный файл
В данном файле описана структура файлов и папок проекта.
Цели проекта описаны в README.md

## Структура проекта
```
Avalon/
├── README.md
├── AGENTS.md
├── CLAUDE.md
├── .gitignore
├── .env.example
│
├── docs/
│   ├── structure.md
│   ├── plan.md
│   ├── status.md
│   └── decisions.md
│
├── project-stages/
│   └── 01-stage-name/
│       ├── tasks/
│       ├── results/
│       └── knowledge/
│
├── technical/
│   ├── home-stand.md
│   └── work-stand.md
│
├── infrastructure/
│   ├── compose.yaml

│       └── superset_config.py
│
└── sql/
    ├── schemas/
    ├── transformations/
    └── checks/
```
## Описание структуры проекта
### Avalon
Корневая папка проекта, в которой хранится всё связанное с проектом.
**README.md** - общая информация о проекте.
**AGENTS.md** - информация о правилах работы агента над проектом.
**CLAUDE.md** - инструкция для Claude Code
#### docs
**structure.md** - информация о структуре файлов и папок проекта.
**plan.md** - общая информация о плане проекта и этапах его реализации.
**status.md** - текущее состояние всего проекта. Что работает, что не работает.
**decisions.md** - описывает принятые решения и причины. Старые решения не удаляем: если подход изменился, отмечаем замену.
#### project-stages
**01-stage-name** - папка в которой поэтапно происходит реализация проекта
**tasks** - папка с задачами по этапу. Задачи в формате Markdown формирует агент после завершения этапа. Пользователь по своему усмотрению может дополнять файлы или менять их расширение.
 **results** - папка с результатам работы по этапу, артефакты которые могут пригодиться для дальнейшей работы. Артефакты формирует агент в любом удобном формате, который посчитает нужным. Пользователь по своему усмотрению может дополнять файлы или менять их расширение. Например написанная процедура и т.д.
 **knowledge** - папка с артефактами которые пользователь может вынести в качестве знаний по данному проекту.
#### technical
В папке хранится техническая информация о проекте.
**home-stand.md** - описание устройства домашнего стенда.
**work-stand.md** - описание устройства рабочего стенда.
#### infrastructure и sql
Актуальные конфигурации и SQL, без копирования по этапам.
