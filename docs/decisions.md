## DEC-001. MVP на синтетических данных

Дата фиксации: 2026-10-30
Статус: принято пользователем в README.md

Использовать реальную структуру данных и бизнес-логику,
но синтетические значения для MVP и демонстрации.
Перенос в PROD — дальнейшее решение компании.
AI не получает корпоративные выгрузки, дампы и результаты запросов
с рабочими данными. Это ограничение сохраняется независимо от места хранения.

## DEC-002. Эталонные конфигурации и отдельный запуск

Дата фиксации: 2026-10-30
Статус: принято

infrastructure/ хранит общие конфигурации и шаблоны без секретов в Git.
Фактический запуск — из отдельного локального каталога с собственными .env.
Общие изменения сначала вносятся в эталон, затем переносятся в рабочую копию;
экстренные полезные исправления переносятся обратно без секретов.
Автоматической синхронизации копий нет.

Домашний стенд будет приведён к общей конфигурации отдельной задачей
этапа 3 после проверки рабочего стенда, с резервными копиями и
сохранением существующих данных. Локальные настройки могут различаться.

## DEC-003. Контейнерный стек и права

Дата фиксации: 2026-10-30
Статус: принято и частично проверено

Использовать два Compose-проекта postgres и superset с общей сетью bi-net,
named volumes и публикацией портов только на loopback хоста.
Версия Superset 3.1.1 взята из комплекта Claude; обновление — отдельная задача.
Docker используется через sudo, группы не меняются.
Для BI создана отдельная роль чтения, права проверены на синтетической таблице.

Запуск и init прошли, но сетевой доступ с хоста пока не работает.
Архитектурное решение не означает завершённую приёмку.

## DEC-004. Устранение проблемы доступа совместно с администратором

Дата фиксации: 2026-10-30
Статус: принято; исправление не выполнено

Передать диагностику администратору ВМ или специалисту по KESL.
Не отключать защиту и не удалять правила Docker как обход проблемы.
Причина выбора — подтверждённое отбрасывание тестовых пакетов и
маршрут через lo для метки KESL; точную настройку продукта должен
проверить ответственный администратор.

[Диагностика и текст обращения](../project-stages/01-make-stand/incident-01-superset-access.md).
Судьбу временного исключения UFW согласовать при исправлении.
