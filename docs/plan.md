# Этап 1. Развернуть инфраструктуру на рабочем стенде.
1. Необходимо получить список всех зависимостей которые есть на домашнем стенде.
2. Развернуть аналогичные зависимости на рабочем стенде.

Текущее состояние: Docker и сервисы развёрнуты, init успешен;
права чтения проверены. Этап не завершён: доступ к Superset с хоста
требует решения администратора ВМ/KESL.
[Задача развёртывания](../project-stages/01-make-stand/task-02-make-stand.md).

# Этап 2. Зафиксировать всю имеющуюся базу знаний
1. Всю ранее полученную информацию которую пользователь посчитает полезной для дальнейшего переиспользования необходимо зафиксировать в виде знаний.

# Этап 3. Обкатка стендов
1. Запуск, отладка, просмотр логов.
2. Уверенное использование.
3. Привести домашний и рабочий стенды к общей конфигурации из infrastructure/ после проверки рабочего стенда. Для домашнего стенда проверить отличия, подготовить резервные копии и локальные настройки, переключить запуск с сохранением данных и проверить работу. Секреты и данные между стендами не синхронизировать.
