## Текущее препятствие

Диагностика указывает на конфликт обработки трафика KESL
с сетевой защитой Docker. Для метки 0x100 маршрут к контейнеру
идёт через lo; во время теста растёт счётчик DROP в raw/PREROUTING.
Точный способ исправления требует проверки администратором ВМ/KESL.

Пользователь добавил узкое исключение UFW перед общим запретом;
этого оказалось недостаточно. Системную защиту не отключали.
Подробности и текст обращения:
[проблема доступа к Superset](../project-stages/01-make-stand/incident-01-superset-access.md).
