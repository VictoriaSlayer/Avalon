## Проверка роли чтения

<DB_ADMIN_USER> — административная роль, создающая таблицы.
<BI_READ_ROLE> — отдельная роль чтения для Superset.

Подтверждены парольный вход <BI_READ_ROLE> по TCP и чтение
двух вымышленных строк из public.avalon_permissions_demo через SET ROLE.
Проверка has_table_privilege для SELECT / INSERT / UPDATE / DELETE:
t / f / f / f. Права по умолчанию применились к новой таблице,
созданной <DB_ADMIN_USER>. Это не проверка прав на все будущие схемы.

## Препятствие и дальнейшие проверки

Диагностика указывает на конфликт обработки трафика KESL с Docker.
[Описание инцидента и сведения для администратора](../project-stages/01-make-stand/incident-01-superset-access.md).

Требуется решение администратора ВМ/KESL. Защитные механизмы
не отключались; временное узкое исключение UFW не устранило проблему.
До пересоздания сетей нужно учесть привязку исключения к текущим адресам.

Не подтверждены:
- доступ к UI и смена стандартного пароля администратора;
- подключение Superset к учебной базе и тестовый график;
- сохранность после перезапуска / перезагрузки;
- резервное копирование и пробное восстановление.

Не считать стенд полностью принятым до выполнения этих проверок.
