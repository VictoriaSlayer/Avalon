# Задача 02: развернуть рабочий BI-стенд

> Статус: актуален
> Обновлено: 2026-11-03 16:49 MSK
> Ответственный: Codex и Saint

Порядок работ:
1. Проверить текущее состояние ВМ и поддержку Ubuntu официальным установщиком Docker.
2. Установить Docker Engine и Compose в систему; первоначально работать через sudo, без изменения групп.
3. Извлечь конфигурации из документа Claude в Avalon/infrastructure/, внести обсуждённые исправления.
4. Подготовить ~/bi-stand/, скопировать конфигурации. Ты задаёшь новые секреты локально.
5. Создать сеть bi-net, запустить учебный PostgreSQL, проверить готовность и создать роль чтения для Superset.
6. Запустить служебную БД, Redis и Superset; проверить завершение инициализации.
7. Открыть Superset через SSH-туннель, подключить учебную базу и построить график на синтетических данных.
8. Проверить сохранность после перезапуска; записать результаты в документацию.

## Выполнение на 2026-11-03

Шаги 1–6 выполнены. По сообщениям пользователя на шаге 7 подключена
учебная БД, создан табличный график и сохранён дашборд.
После stop/start сервисы healthy, /health с хоста — HTTP 200.

в браузере ещё не подтверждена; шаг 8 пока не закрыт полностью.
