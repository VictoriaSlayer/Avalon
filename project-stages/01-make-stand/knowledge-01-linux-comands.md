## cat /etc/os-release

`cat` выводит содержимое файла в терминал.
`/etc/os-release` — файл с описанием установленной операционной системы.

```bash
cat /etc/os-release
```

Основные поля:
- `PRETTY_NAME` — полное название ОС и версии для отображения.
- `VERSION_ID` — номер версии дистрибутива.
- `VERSION_CODENAME` — кодовое имя выпуска.
- `ID` — идентификатор дистрибутива.

На рабочем стенде пользователь получил Ubuntu 26.04.1 LTS,
`VERSION_ID="26.04"`, кодовое имя `resolute`.

Назначение: определить выпуск Ubuntu для выбора совместимых пакетов
и ветки репозитория при установке Docker.

## dpkg --print-architecture

`dpkg` — инструмент управления пакетами Debian и Ubuntu.
Параметр `--print-architecture` выводит основную архитектуру пакетов,
для которой настроена система.

```bash
dpkg --print-architecture
```

Результат рабочего стенда: `amd64` — 64-битная архитектура x86,
используемая процессорами Intel и AMD. Это не означает, что процессор
обязательно произведён AMD.

Назначение: выбрать сборку пакетов для архитектуры системы.
Обозначение `amd64` соответствует архитектуре, которую
`uname -m` обычно показывает как `x86_64`.

## Безопасность и проверка

Обе команды только читают сведения: не меняют настройки, ничего
не устанавливают и не требуют `sudo`.

**Проверено:** пользователь выполнил обе команды на рабочей ВМ
и передал вывод 2026-10-29.
