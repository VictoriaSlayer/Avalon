**Владелец процесса:** договорной отдел;

**Цель процесса:**  
- подготовка проекта договора;
- согласование проекта договора для его дальнейшего подписания;

**Выполняемые действия в рамках процесса:**
- проверка всей необходимой информации для подписания договора:
- тех. задание;
- сметы;
- графики;
- иная документация;
- согласование _Договора в 1С ДО_;

**Метрики процесса:**
- скорость согласования Договора в 1С;
- качество документов (количество отклоненных документов в 1С ДО);

**Используемое ПО:** 1С ДО;

**Данные:** хранятся в 1С ДО в карточке документа;
