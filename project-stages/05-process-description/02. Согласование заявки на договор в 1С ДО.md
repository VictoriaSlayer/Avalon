**Цель процесса:**
- подготовить всю информацию необходимую для подготовки проекта договора;
- согласовать заявку на подготовку договора;

**Выполняемые действия в рамках процесса:**
- сбор всех необходимых документов о контрагенте, обязательствах сторон, сроках, вопросах ценообразования;
- согласование _Заявки на подготовку договора в 1С_;

**Метрики процесса:**
- количество заявок от инициатора;
- скорость согласования заявки в 1С в рабочих днях;
- качество документов (количество отклоненных документов в 1С ДО);

**Используемое ПО:** 1С ДО;
