# Иерархия создания дашборда
![[Pasted image 20261108201556.png]]

SQL -> Dataset -> Charts -> Dashboards

## Как это устроено в цепочке работы
- Вы подключаете **базу данных** к Superset.
- Создаете на её основе **датасет** (из таблицы или через SQL).
- На базе датасета собираете **чарты** (диаграммы, таблицы, графики).
- Объединяете чарты в интерактивные **дашборды**.
## SQL
Предназначен для манипуляций с данными на уровне SQL.
SQL lab - встроенный SQL-редактор и интерактивная «песочница» (IDE), которая входит в состав аналитической платформы Apache Superset.
Основные возможности
- **Написание и запуск запросов:** Строго только DML. 
  Позволяет составлять SQL-скрипты разной сложности (от простых `SELECT` до сложных объединений и оконных функций) и сразу видеть результат в виде таблицы. 

- **Работа с разными источниками:** Подключается к популярным базам данных и хранилищам (PostgreSQL, ClickHouse, BigQuery, Snowflake, Trino и др.).

- **Создание виртуальных датасетов:** Позволяет сохранить результат написанного в SQL Lab запроса как готовый набор данных, который затем можно использовать для построения графиков и дашбордов в Apache Superset. 

- **Исследование структуры БД:** Дает возможность просматривать схемы баз данных, таблицы, колонки и типы данных прямо в интерфейсе.

## Dataset
Логическая обертка над источником из БД. На основе этой обертки строятся Charts, Dashbords.
Superset не копирует и не сохраняет данные у себя. Датасет лишь описывает, откуда и как брать информацию при обращении к вашей базе данных.

Бывают виртуальные и физические:
- **виртуальные** - создаются на основе произвольного SQL-запроса в SQL Lab, позволяя объединять таблицы, делать фильтрацию или расчеты еще до построения графиков;
- **физические** - прямая ссылка на конкретную таблицу или представление в подключенной БД;

  **ВАЖНО!!!** на основании таблицы из БД может быть создан только один датасет с типом physical и множество с типом virtual.
### Хранилище бизнес-логики
В настройках датасета вы можете задать:
- **Метрики (Metrics):** Готовые агрегирующие выражения (например, `SUM(sales)`, `COUNT(*)`);
- **Столбцы (Columns):** Типы данных, формат отображения чисел и дат;
- **Фильтры по умолчанию (Calculated/Default filters):** Правила, которые будут применяться ко всем чартам на основе этого датасета;

## Chart
Chart - вариант визуализации на основе Dataset. Отдельный график, диаграмма или таблица, которая визуализирует данные из датасета. Это кирпичик, из которого строятся интерактивные дашборды.

- **Строится строго на основе датасета:** Каждый чарт жестко привязан к одному конкретному датасету (физическому или виртуальному).
- **Огромный выбор типов визуализаций:** В Superset встроены десятки вариантов отображения данных — от базовых (линейные графики, круговые диаграммы, сводные таблицы) до продвинутых (тепловые карты, географические карты Deck.gl, воронки продаж и графы).
- **Конструктор без кода (Explore):** Для создания чарта не нужно писать SQL-код. Вы перетаскиваете мышкой нужные метрики и измерения (группировки) в левой панели интерфейса, а Superset сам генерирует SQL-запрос к базе данных и рисует график.
- **Настройка внешнего вида:** Внутри чарта можно менять цвета, форматировать числовые оси (например, добавлять знак валюты или процента), настраивать легенду и сортировку.
